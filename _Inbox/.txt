Kangi Admin Dashboard — What It Does

Overview The dashboard is a private web portal for the Kangi team. Everything is password-protected — only accounts with admin access can log in.

NFT Management

Create digital collectible batches (NFTs) with an image, name, and notes
Each batch generates a set of unique QR codes automatically
View all created NFT batches in one library
Download individual QR codes as image files
Copy shareable redemption links
See a live count of how many QR codes have been used vs. still available
Manually redeem a QR code by pasting the code into the dashboard
Music / Sounds Library

View all audio tracks submitted by users from the app
New submissions sit in a "Pending" state until reviewed
Approve a track to make it live and visible in the app
Delete a track to remove it from the platform permanently
Filter the list to show All, Pending only, or Approved only
Preview any track directly in the browser before deciding
User Management

See a full list of every registered player
Search users by name, email, or ID
Open any user's profile to see their account details, status, and unlocked characters
Grant admin access to a user
Revoke admin access from a user
Suspend a user for 3 days, 7 days, or permanently
Lift a suspension and restore a user's account
Send a direct notification message to any user from their profile
Messages Inbox

View all support messages sent by players from inside the game
Messages show the player's name, their message, and when it was sent
Reply directly to any message — the player receives the reply as a notification in-game
Open messages are marked separately from replied ones
Delete messages once resolved
Notifications

When the admin approves or deletes a song, the artist automatically gets a notification in-game
When a user is suspended or reinstated, they receive an automatic in-game notification
When admin access is granted or revoked, the user is notified
When the admin replies to a support message, it arrives as an in-game notification for the player
Dashboard Stats

At a glance: total NFT collections created, total QR codes generated, and total redemptions completed
Settings & Account

View the currently logged-in admin account
Switch between dark and light theme
Sign out securely
